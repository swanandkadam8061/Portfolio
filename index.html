01 Hackathon Project

VoiceKhata — Voice Ledger for Shopkeepers

Problem Statement

Small shopkeepers and local vendors in India often lack the digital literacy or time to maintain written financial records. Manual ledger-keeping is error-prone, slow, and inaccessible to those who cannot type efficiently.

Solution Overview

VoiceKhata is a browser-based voice-powered ledger application that lets shopkeepers record credit (Udhar) and debit transactions by simply speaking. The app transcribes voice input, extracts monetary values, and maintains a running ledger — entirely in the browser with zero backend required.

Architecture

Client-side only (HTML + CSS + Vanilla JS). Uses the Web Speech API for real-time speech recognition, localStorage for persistent offline data, and a custom NLP parser to extract amounts and transaction type from natural language input.

My Contribution

Built the speech-to-ledger pipeline including the voice command parser, transaction state machine, and UI. Collaborated in a hackathon team environment to deliver the full MVP within the event timeframe.

02 Personal Project

Browser-Based AI Portfolio Assistant

Problem Statement

Traditional portfolio websites are static — visitors read text but cannot ask questions or navigate interactively. AI-powered chat requires expensive API keys and backend servers, limiting accessibility for student developers.

Solution Overview

An interactive AI assistant embedded directly into this portfolio that answers questions about my projects, skills, and background. It runs entirely offline using scripted response logic with a fallback to Ollama (local LLM) for extended conversations — no API key required.

Architecture

Pure client-side implementation. The assistant uses a keyword-matching intent engine for fast, deterministic responses. Optionally, users can point it to a local Ollama endpoint (e.g., Gemma or Mistral) for open-ended conversation. Built as a dialog element with accessible keyboard focus management.

My Contribution

Sole developer. Designed the intent engine, wrote the response corpus, implemented accessible dialog UI, and integrated optional Ollama streaming API. Also built the Three.js 3D interactive guide characters that accompany the assistant.
