VoiceKhata

A voice ledger for neighbourhood shops

A shopkeeper can say who bought on credit, review the name and amount, then save the entry. The browser preview stores entries on the device. In the full application, the same interface sends confirmed transactions to a FastAPI service backed by SQLite.

My contributions

  • I connected the review form to the signed-in ledger and kept failed server saves visible to the user. PR #9
  • I fixed Hindi parsing so a list of items stays on one bill. Spoken amounts and uncertain transaction types remain editable before saving. PR #14 · PR #15
  • I moved Whisper’s warm-up ahead of recording and added a retry that preserves manual corrections. PR #16
Earlier voice and ledger work
  • I added a faster-whisper speech-to-text demo. PR #7
  • I refined Hindi recording, added CSV backup and clarified when Google sign-in is available. PR #11 superseded my earlier PR #10.
  • I repaired the Whisper loader and added a local shop portal with a device PIN. PR #12 · PR #13

Open-source coursework.

I submitted ten Python labs to S-AI-Projects/AI-For-Beginners as swanandkadam8061. Each pull request includes a runnable example, tests and lesson notes.

  1. R38-T051PR #81 ↗

    Selecting a genetic algorithm’s elite

    I sorted candidates by fitness and broke ties by ID. That makes selection repeatable even when two candidates have the same score.

  2. R38-T052PR #82 ↗

    Cosine similarity at the boundaries

    I checked vector dimensions and returned an explicit undefined result for a zero vector, so callers can distinguish it from a valid similarity of zero.

  3. R38-T053PR #83 ↗

    Ordering a dependency plan

    I implemented topological sorting and checked for cycles and missing dependencies. The planner can catch an impossible schedule before a task starts.

  4. R38-T054PR #84 ↗

    Tracing an agent’s routing decision

    I added intent rules, a fallback handler and a record of each decision. The trace shows which rule took priority when a request matched more than one.

  5. R38-T055PR #85 ↗

    Evaluating a binary classifier

    I computed a confusion matrix, precision and recall from fixed labels. Tests cover zero denominators so the result is predictable when a class has no examples.

  6. R38-T056PR #86 ↗

    Separating calculation from presentation

    I split the cosine similarity calculation from its report formatter. A lesson can change how it presents a result without changing the underlying calculation.

  7. R38-T057PR #87 ↗

    Working through an embedding comparison

    I returned the dot product and both vector norms alongside the final similarity. A learner can check each step by hand and see where a zero vector makes the result undefined.

  8. R38-T058PR #88 ↗

    Following one perceptron update

    I implemented a prediction and weight update for a two-dimensional input. A test follows a misclassification through the update and checks the rule for a score of zero.

  9. R38-T059PR #89 ↗

    Normalizing a batch of images

    I validated the batch dimensions and rescaled pixels from 0–255 to 0–1. Checking the output shape catches inputs that would otherwise lose their image structure.

  10. R38-T060PR #90 ↗

    Filling missing values without leakage

    I fitted the replacement mean on training observations and reused it for validation. This keeps information from the validation set out of preprocessing.
